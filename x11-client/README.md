# xSGINet client

X11 motif client for SGINet.
Please register your machine with the sginet CLI first, before you launch xsginet.

(c) flexion 2025

# Building

xsginet is built from the top directory with native IRIX compilers, no SGUG-RSE needed.
See [BUILDING.md](../BUILDING.md):

    make xsginet           # IRIX 6.x / MIPSpro
    smake xsginet-irix5    # IRIX 5.x / IDO cc

# Start xSGINet

    xsginet
